# Boxiang Song

A bilingual academic homepage for Boxiang Song, a Ph.D. student at CODA Lab, Fudan University.

Website: https://boxiang-song.github.io/

## Features

- Chinese and English language switch
- Research interests, publications, education, and awards
- Verified paper links and BibTeX citations
- Responsive layout and personal photograph
- Plain HTML, CSS, and JavaScript with no build dependencies

## Editing

Edit `index.html` for page structure, `style.css` for typography and layout, and `app.js` for publication data and bilingual text. The portrait is stored as `boxiang-song.jpg`.

## Hosting

Published with GitHub Pages from the root of the `main` branch. The `.nojekyll` file disables Jekyll processing.
